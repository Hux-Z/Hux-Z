## 你好，我是嘉亮

我有 13 年汽车品牌、产品与区域业务经验，长期关注品牌表达、用户旅程与客户体验。现在也用 AI Coding 制作轻量工具和内容工作流，并以 PADI / EFR 潜水教练的身份继续做课程教学与海外行程。

我习惯先弄清楚用户的目标、经验和限制，再把策略变成现场可以执行的下一步。
